# Apocalypse

Pack Minecraft Forge 1.20.1 avec le mod AI Guardian.

## Installer

1. Avoir Minecraft Java et avoir ouvert le launcher Minecraft officiel une fois (connecté à son compte Microsoft).
2. Télécharger [Apocalypse.exe](https://github.com/Shiiroww/apocalypse-pack/raw/main/Apocalypse.exe) et le lancer.
3. Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires », puis « Exécuter quand même ».
4. Attendre la fin de l'installation (environ 540 Mo), cliquer sur JOUER, puis sur Jouer dans le launcher Minecraft (profil « Apocalypse »).

Pour mettre le pack à jour : relancer `Apocalypse.exe`.

Les mods ne sont pas hébergés ici : le launcher les télécharge chez CurseForge.
