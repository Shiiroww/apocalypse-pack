# Apocalypse

Pack Minecraft Forge 1.20.1 avec le mod AI Guardian.

## Installer

1. Avoir Minecraft Java Edition (acheté sur un compte Microsoft). Rien d'autre à installer.
2. Télécharger [Apocalypse.exe](https://github.com/Shiiroww/apocalypse-pack/raw/main/Apocalypse.exe) et le lancer.
3. Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires », puis « Exécuter quand même ».
4. Cliquer sur SE CONNECTER : la page de Microsoft s'ouvre, coller le code affiché et se connecter. Le mot de passe n'est jamais saisi dans le launcher.
5. Cliquer sur JOUER. La première fois, le launcher télécharge le jeu, Forge et les mods (environ 1,3 Go).

Le pack se met à jour tout seul à chaque clic sur JOUER.

Les mods ne sont pas hébergés ici : le launcher les télécharge chez CurseForge.
